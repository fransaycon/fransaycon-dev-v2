# fransaycon.dev

Personal portfolio and landing site for **Franrey Saycon** — software architect and engineering leader. Built as a single-page, server-rendered experience showcasing a hero intro, work stats, a projects gallery with an animated modal, past clients, and a contact form.

## Tech stack

- **[TanStack Start](https://tanstack.com/start)** + **[TanStack Router](https://tanstack.com/router)** — file-based routing with SSR, on top of **Vite**.
- **React 19** (function components, TypeScript `strict`).
- **[Tailwind CSS v4](https://tailwindcss.com/)** — CSS-first config in `src/styles.css` (no `tailwind.config.js`).
- **[Motion](https://motion.dev/)** (Framer Motion) for shared-layout animations.
- **[Biome](https://biomejs.dev/)** for linting/formatting, **Vitest** + Testing Library and **Playwright** for tests.
- **[@t3-oss/env-core](https://env.t3.gg/)** + **zod** for validated environment variables.
- Deployed to **Netlify**. Package manager: **pnpm** (Node >= 22).

## Getting started

```bash
pnpm install
cp .env.example .env   # then fill in the values (see below)
pnpm dev               # http://localhost:3000
```

## Environment variables

Env is validated in [`src/env.ts`](src/env.ts). Client-exposed vars must be prefixed `VITE_`.

| Variable | Required | Description |
| --- | --- | --- |
| `VITE_WEB3FORM_ACCESS_KEY` | for contact form | [Web3Forms](https://web3forms.com) access key that powers the contact form submission. |
| `VITE_SITE_URL` | optional | Canonical site origin used to build absolute URLs for SEO/social meta tags. Defaults to `https://fransaycon.dev`. |

Copy `.env.example` to `.env` for local development. In production, set these under **Netlify → Site settings → Environment variables** (they are inlined at build time, so redeploy after changing).

## Project structure

```
src/
├── routes/          # File-based routes (__root.tsx layout + index.tsx home)
├── components/      # UI sections & pieces (hero, projects, contact, dividers…)
├── hooks/           # Reusable hooks (e.g. use-in-view)
├── data/            # Typed content (projects.ts)
├── animation/       # Lottie JSON
├── project-files/   # Project preview images
├── work-logos/      # Client/company logos
├── fonts/           # Self-hosted Moon font
├── env.ts           # Validated environment variables
└── styles.css       # Tailwind v4 theme + global styles
```

`src/routeTree.gen.ts` is generated by TanStack Router — don't edit it by hand.

## Conventions

- **Commits** follow [Conventional Commits](https://www.conventionalcommits.org/), enforced by commitlint via a Husky `commit-msg` hook. Use `pnpm commit` for a guided message.
- A **lint-staged** pre-commit hook runs Biome auto-fix + `tsc --noEmit`. Don't bypass with `--no-verify`.
- Use path aliases `#/*` (or `@/*`) for `src/*` imports.
- Prefer TanStack loaders/server functions over `useEffect` data fetching; keep components pure for SSR.

## Deploy to Netlify

`netlify.toml` is preconfigured:

1. Push this repo to GitHub.
2. Import it at <https://app.netlify.com/start>.
3. Netlify auto-detects the build (`vite build` → `dist/client`).
4. Add the environment variables above under **Site settings → Environment variables**.
5. Trigger the first deploy.

Server functions and API routes run on Netlify Functions. For lower-latency handling, see [Netlify Edge Functions](https://docs.netlify.com/edge-functions/overview).
